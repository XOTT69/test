# 🏠 Оселя — Telegram Bot

Приватний домашній органайзер у Telegram: повноцінний **Mini App** з біло-фіолетовим інтерфейсом, а також чат-бот із нагадуваннями.

Функції: фільтри для води, заміна картриджів, повторювані домашні справи, покупки, витрати, аптечка, сімейний доступ, Mini App, кольорове виділення строків заміни, нагадування о 09:00 (Europe/Kyiv), експорт/імпорт JSON. Дані кожного Telegram користувача відокремлені.

## Підготовка
Встановіть Node.js 20+ та зайдіть у Cloudflare.

1. git clone --branch oselya-telegram-bot --single-branch https://github.com/XOTT69/test.git oselya-telegram-bot
2. cd oselya-telegram-bot
3. npm install
4. npx wrangler login
5. npx wrangler d1 create oselya-bot-db
6. Якщо розгортаєте в іншому Cloudflare-акаунті — змініть database_id у wrangler.toml (для чинного проєкту вже вказано потрібний ID).
7. npm run db:remote
8. npx wrangler secret put BOT_TOKEN
9. npx wrangler secret put WEBHOOK_SECRET
10. npm run deploy

WEBHOOK_SECRET — власний випадковий рядок із 32+ символів A-Z, a-z, 0-9, дефіс або підкреслення. BOT_TOKEN — токен нового бота від BotFather. Не публікуйте обидва!

## Webhook
Після deploy Cloudflare видасть Worker URL. Викличте Telegram API setWebhook, передавши url рівним Worker URL плюс /telegram та secret_token, рівний WEBHOOK_SECRET. Метод POST. У README навмисно відсутні реальні токени.

Доступ обмежено через GitHub Secret ALLOWED_USERS, який під час автоматичного деплою перетворюється на Worker Secret. Не додавайте особистий ID у публічний wrangler.toml.

## Важливо
Імпорт підтримує тільки JSON резервної копії цього бота. Старий сайт та його база не змінюються. Потрібна окрема міграція зі старого вебзастосунку. Це початковий бот; перед застосуванням до важливих даних протестуйте резервні копії.

## Запуск без ПК через GitHub Actions

У гілці `oselya-telegram-bot` є `.github/workflows/deploy-oselya.yml`. Після додавання 5 Repository Secrets він автоматично застосує D1-міграції, розгорне Worker, встановить Worker Secrets і зареєструє Telegram webhook.

Відкрийте GitHub → XOTT69/test → Settings → Secrets and variables → Actions → New repository secret. Створіть:

- `CLOUDFLARE_ACCOUNT_ID` — ID акаунта Cloudflare, де створена D1.
- `CLOUDFLARE_API_TOKEN` — окремий Cloudflare API token із дозволами для Workers та D1 Edit, обмежений необхідним акаунтом.
- `BOT_TOKEN` — токен від @BotFather.
- `WEBHOOK_SECRET` — випадковий рядок з 32–256 символів A-Z, a-z, 0-9, дефіс або підкреслення.
- `ALLOWED_USERS` — числовий Telegram user ID власника (кілька ID — через кому).

Токени додавайте **лише в Actions Secrets**, не в коміти чи відкриті файли. Після збереження секретів: GitHub → Actions → Deploy Oselya Telegram Bot → останній запуск → Re-run all jobs. Якщо запуск відсутній, створіть новий коміт у цій гілці. Після успіху відкрийте бота й надішліть `/start`.

За відсутності секретів workflow **не розгортає** проєкт. `ALLOWED_USERS` обов'язковий, щоб захистити особисті дані. Перевірка `npm test` у гілці перевіряє лише синтаксис; експорт, імпорт і нагадування необхідно додатково перевірити перед використанням із важливими даними.

## Фільтри та інтервали

Фільтри можна додати до конкретної системи осмосу. Інтервал заміни задається у днях, місяцях або кінцевою датою, а в картках і списках відображається одночасно календарний залишок (місяці та дні) та загальна кількість днів. Статуси: 🔴 заміна сьогодні або прострочена, 🟠 заміна протягом 7 днів, 🟢 більше 7 днів. Заміна одним натисканням автоматично переносить наступну дату за тим самим інтервалом.

Функцію TDS прибрано. Міграція `0003_remove_tds.sql` видаляє попередні TDS-вимірювання з бази та незавершені сеанси введення TDS. У резервні копії вимірювання більше не потрапляють; під час імпорту старих копій вони пропускаються. Інші записи (осмос, фільтри, справи, покупки, витрати, історія замін) зберігаються.

## Оновлення домашнього органайзера

- **📅 План на тиждень:** спільний перелік прострочених і запланованих домашніх справ та замін картриджів.
- **🚰 Мій осмос:** картка з назвою, моделлю, датою встановлення та власними картриджами; ці поля можна редагувати.
- **📋 Справи:** редагування назви, строку, повторення; виконання прямо з повідомлення Telegram.
- **🔔 Розумні нагадування:** о 09:00 за Києвом — за 7 днів, за день, у день події та кожні 3 дні після прострочення. Кнопки «Замінено/Виконано» та «Завтра». У налаштуваннях можна вимкнути повідомлення або попередження за 7 днів.
- **📊 Статистика:** витрати за місяць/рік/весь час, кількість замін картриджів, активні та завершені справи.
- **👨‍👩‍👧 Сім’я:** власник створює одноразове запрошення у Telegram. Посилання діє 24 години. Після прийняття учасники працюють з одним набором фільтрів, осмосів, справ, покупок та витрат. Учасники можуть редагувати спільні дані. Власник керує списком і може відкликати доступ; самі учасники можуть вийти. Налаштування сповіщень особисті. Перед приєднанням особистий профіль учасника повинен бути порожнім — бот не зливає дані автоматично.
- **🧰 Домашня аптечка:** облік запасів, місця зберігання, термінів придатності й поповнення, без медичних призначень і рекомендацій із дозування.
- **Резервні копії:** власник може експортувати/імпортувати дані; сімейні запрошення не експортуються.

Налаштування бази — автоматичні через `migrations/`. Міграції додають таблиці без скидання старих записів. Не вставляйте персональні або секретні токени в GitHub.


## 🧰 Домашня аптечка

У Telegram відкрийте «🧰 Аптечка» або /medicine. Можна вести окремий запис для кожної упаковки чи партії з власним терміном придатності. Кожен запис має назву, маркування/форму (як написано на упаковці), залишок, одиницю, кінцеву дату, поріг поповнення, місце зберігання й примітку.

Термін можна вказувати **ДД.ММ.РРРР** або **ММ.РРРР** (в останньому випадку бот використовує останній календарний день місяця, з урахуванням високосних років). Якщо дата невідома, можна зазначити дефіс; бот не вигадує термін і не надсилає нагадування про його закінчення.

Кнопки: «Списати 1» (віднімає одну одиницю запасу, а не рекомендує дозу), «Поповнити», «Редагувати», «До архіву»; архів можна відновити. Зміни запасу зберігаються в історії. Статуси терміну та малих запасів відображаються в меню. Нагадування о 09:00 за Києвом: за 30/7/1 день до завершення, у день завершення та наступного дня; окреме попередження при мінімальному або нульовому запасі (без щоденного спаму). Налаштування сповіщень — персональні для кожного користувача.

**Приватність:** список аптечки спільний для запрошених членів сім'ї, як і інші розділи. Не вносіть зайвої медичної інформації у примітки. Функція призначена лише для домашнього обліку запасів, а не для порад щодо прийому ліків, дозувань, лікування чи умов зберігання. Завжди звіряйтеся з упаковкою та інструкцією.

Резервні копії /export і /import включають аптечку та історію зміни кількості; імпорт старих резервних копій без цих полів залишається доступним.


## 🚀 Telegram Mini App (готовий до використання)

**Застосунок:** https://oselya-telegram-bot.mikolenkoanton7.workers.dev/app

Відкрийте Telegram-бота → **Меню → 🏠 Оселя** або скористайтеся кнопкою «✨ Відкрити Оселю» після /start. На iOS Mini App відкриється в Telegram WebView. Звичайне відкриття URL у Safari показує інформаційну сторінку: отримати свої дані можна лише після перевірки Telegram WebApp initData.

Після зміни коду гілки `oselya-telegram-bot` workflow автоматично запускає тести, оновлює Worker, підключає Telegram webhook і встановлює кнопку меню через `setChatMenuButton`. Приватні токени залишаються у GitHub Actions Secrets.
